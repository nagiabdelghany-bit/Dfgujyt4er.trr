# Dfgujyt4er.trr

## مختبر Excel التفاعلي

صفحة عربية تفاعلية لتدريب المبتدئين على أساسيات Excel، وتشمل:

- جولة مرئية داخل ورقة العمل والخلايا والصيغ والمخططات.
- تبويبات تعليمية تتغير دون إعادة تحميل الصفحة.
- اختبار قصير من 3 أسئلة مع تصحيح فوري ونتيجة نهائية.
- تصميم متجاوب يعمل على الهاتف والكمبيوتر.

افتح `index.html` مباشرة أو انشر المستودع عبر GitHub Pages.

تظل لوحة المشرف الأصلية في `admin-dashboard.html` دون تعديل.
